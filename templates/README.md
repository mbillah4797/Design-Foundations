# Templates

Fill-in forms that put the rules into practice. Copy them, change them, reuse them freely.

| Template | Use it for |
|---|---|
| [question-with-default.md](question-with-default.md) | Any question to a person: options, one recommendation, what happens on silence, and a record of the answer. |
| [decision-record.md](decision-record.md) | One entry in the decision log: who decided, their words, why, and what enforces it. |
| [adversarial-verify-brief.md](adversarial-verify-brief.md) | A step whose only job is to find holes in another agent's work. |
| [agent-brief.md](agent-brief.md) | The skeleton of any agent step: checkpoint, goal, facts, scope, authority, return format. |
| [release-checklist.md](release-checklist.md) | A production release run by one owner, with safe aborts and a named rollback. |
| [limits-not-done-footer.md](limits-not-done-footer.md) | The section every agent report ends with, and the reader reads first. |
| [blind-panel-brief.md](blind-panel-brief.md) | A design review by reviewers who did not make the design and see only pictures. |
